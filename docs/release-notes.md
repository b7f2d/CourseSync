# CourseSync

将教务课程同步至 Apple 日历，支持手动刷新、快捷指令自动同步及课程变动更新。所有学校登录请求均由设备直接发起，无需自建服务器。

**安装：** 下载下方的 `CourseSync.zip`，使用 iOS [Scripting](https://scriptingapp.github.io/) 导入，按提示完成授权和学校登录。

**使用与更新：** [查看用户指南](https://github.com/b7f2d/CourseSync#用户指南)。

> 非官方项目。请使用独立的专用日历，并在首次同步后核对课程信息。自动执行受 iOS 后台运行限制。

> 更名说明：Scripting 脚本名称、GitHub 仓库和稳定版 ZIP 文件名均为 `CourseSync`。老版本数据会在首次运行时尝试安全迁移；请核对后再停用旧项目。


### 独立 iPhone 预览版 1.0.5

Release 同时提供 `CourseSync-1.0.5-unsigned.ipa`，适用于 iOS 17 及以上，需要自行签名后安装。此版本不依赖 Scripting；尚未提供桌面小组件、实时活动和快捷指令自动刷新，仍需实机验证。Scripting 用户继续使用 `CourseSync.zip`。

本次修复日历事件重复保存、响应头读取及小组件课程截断问题，并更新考试日历同步逻辑。


版本规则：Scripting ZIP 与独立 IPA 共用 `script.json` 中的版本号。当前为 1.0.5；后续常规变更仅递增末位（1.0.5、1.0.6……），除非明确要求升级大版本。Scripting 的稳定更新地址保持不变。


1.0.4：两版主菜单新增离线「查看课表」，展示最近20节未结束课程；优化提醒查找效率，修复独立版取消选择日历与请求默认值处理。发布前验证独立版取消登录、首次同步与重复刷新。两版核心同步逻辑共用；独立版尚不具备 Scripting 提供的小组件、实时活动与快捷指令能力，界面也未完全一致。

1.0.5：原生学校选择菜单在异常索引下安全取消，增加原生宿主回归测试；Validate 现在在 macOS 构建未签名 IPA 并运行同步冒烟测试，ZIP 打包额外校验实际归档的入口文件与 script.json 版本。两版仍共用同步核心；尚未实现 WidgetKit、ActivityKit 与 App Intents 原生扩展，也尚未实机验证。
