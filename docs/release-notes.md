# CourseSync 稳定版发布

CourseSync 是一款基于 iOS Scripting 的本地高校课表与考试日程同步工具，原生支持 Apple 系统日历、桌面动态小组件及快捷指令自动化后台同步。

### 核心特性

- **全学期与考试同步**：支持同步在校期间所有学期（包含往期历史课表与未来新学期排课及已公布考试），自动识别调课补课，防止重复排程。
- **多校统一支持**：首次登录可选择南京财经大学或苏州科技大学，各校凭据与日历状态在本地独立存储与管理。
- **动态三日小组件**：自适应 iOS 浅色/深色外观，智能识别上课时段并动态聚焦展示昨天、今天与明天的教学日程。
- **安全与纯本地运行**：所有请求直连学校官方系统，无需任何自建服务器或第三方中转，凭据安全保存在 iOS 钥匙串中。

### 安装与更新

1. 下载下方的 `CourseSync.zip` 发布包。
2. 打开 iOS [Scripting](https://scriptingapp.github.io/) 应用，选择「导入远程脚本」完成导入。
3. 详细配置、快捷指令自动化与日常操作请参阅项目主页的 [用户指南](https://github.com/b7f2d/CourseSync#用户指南)。
