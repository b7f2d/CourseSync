# NUFE-Schedule

NUFE-Schedule 是基于 iOS Scripting 与快捷指令开发的课程表同步工具，适用于 NUFE 教务系统。项目通过学校官方统一身份认证及教务接口获取课程数据，并将课程安排同步至 Apple 日历，无需部署独立服务器。

## 主要功能

- **课程同步**：支持多个学期的课程信息读取与日历维护，识别课程新增、调整及取消情况。
- **自动执行**：支持通过 iOS 快捷指令触发同步，同时提供手动刷新、运行状态查询及异常诊断功能。
- **会话管理**：优先复用已建立的登录会话；在用户选择保存账号凭据的情况下，可于会话失效后尝试重新认证。
- **日历展示**：课程标题包含教师姓名，地点显示教室或教学楼信息，备注仅保留最近同步时间。
- **数据一致性**：通过本地状态记录、备份、差异核验及事务恢复机制，降低中断和重复同步带来的影响。

## 数据与隐私

学校认证与课程数据请求由设备直接发起，不依赖第三方账号托管或认证中转服务。用户可选择将账号凭据保存在支持 iCloud 同步的系统钥匙串中；会话 Cookie、设备标识及运行状态保留在设备本地。课程日历是否跨设备同步由用户的 Apple 日历设置决定。

## 安装与使用

下载本 Release 附带的 **`NUFE-Schedule.zip`**，使用 iOS Scripting 导入项目，并根据提示授权日历访问、绑定课表专用日历及完成学校认证。需要定时同步时，可在 iOS 快捷指令中配置相应的 Scripting 自动化操作。

详细安装步骤、更新方式及使用说明请参阅 [README](https://github.com/b7f2d/NUFE-Schedule#readme)。

## 使用说明与限制

本项目为非官方开源工具，与 NUFE 不存在官方隶属关系。学校认证页面或接口调整、验证码及其他交互式认证要求，以及 iOS 后台任务调度限制，均可能影响同步结果。建议在首次导入或更新后核对课程安排，且仅将专用日历用于本项目管理的课程。

本页面持续提供项目的当前发行文件；更新经自动化测试后发布至同一下载地址。
