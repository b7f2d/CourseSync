# NUFE-Schedule

将 NUFE 课表同步至 Apple 日历，支持手动刷新、快捷指令自动同步及课程变动更新。所有学校登录请求均由设备直接发起，无需自建服务器。

**安装：** 下载下方的 `NUFE-Schedule.zip`，使用 iOS [Scripting](https://scriptingapp.github.io/) 导入，按提示完成授权和学校登录。

**使用与更新：** [查看用户指南](https://github.com/b7f2d/NUFE-Schedule#用户指南)。

> 非官方项目。请使用独立的专用日历，并在首次同步后核对课程信息。自动执行受 iOS 后台运行限制。
